## HOW TO UPLOAD LARGE FILES IN PHP
https://code-boxx.com/upload-large-files-php/

## NOTES
1) Gist does not allow folders. After unzipping, create an empty `temp` and `uploads` folder.
2) There are 3 sets of examples. `1`- Basic PHP setting tweak. `2`- Chunk upload. `3`- Resumable upload.
3) For the resumable upload, install [Composer](https://getcomposer.org/) and use it to get the PHP server-side library first – `composer require flowjs/flow-php-server`.
